# Avaluació — proves pràctiques i fulls

**3 proves pràctiques** (una per trimestre), coherents amb els criteris d'avaluació i les rúbriques de la `Programació didàctica`.

| Prova | Trimestre | SA | Maquinari |
|---|---|---|---|
| `Prova_practica_T1.md` | 1r | SA1-SA3 | micro:bit V2 + Micro:shield + sensors bàsics |
| `Prova_practica_T2.md` | 2n | SA4-SA6 | Vehicle T2 (motors + ràdio + control) |
| `Prova_practica_T3.md` | 3r | SA7-SA8 | Rover T3, per estacions rotatives |

## Estructura de cada prova
- **Competències i criteris** avaluats + rúbriques aplicades (R1, R3, R4).
- **Enunciat per nivells**: nucli obligatori (satisfactori) + ampliacions (notable/excel·lent) → atenció a la diversitat.
- **Graella de correcció** (punts + rúbrica).
- **Solució orientativa** per al docent (codi complet, també a `Classes/Solucionari/Proves_T1_T2_T3_solucions.md`) — no es lliura a l'alumnat.

> Durada: una sessió sencera (~100' efectius), integrada dins de SA3 (T1, S4), SA6 (T2, S4) i SA9 (T3, S5, per estacions rotatives). Es permet consultar esquemes i el quadern tècnic propi. Vegeu també `00_LLEGEIX-ME_Avaluacio.md` i les rúbriques a [`../Programació didàctica/07_Rubriques.md`](../Programació%20didàctica/07_Rubriques.md).
