# Classes/00_General

Material transversal del curs (rutines d'aula, glossari, banc d'activació, quadern
tècnic, fil conductor dels robots trimestrals...): tot allò que no és exclusiu d'una
sola SA.

> **Per a qui és?** Docent i alumnat (segons el fitxer): el generador classifica
> automàticament cada document a partir del seu nom (vegeu `tools/qa.py` i
> `web/_generador/generar.py:classify_public`).

Pendent de contingut (es crearà a mesura que s'implementin les SA).
