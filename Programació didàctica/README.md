# Programació didàctica

Programació completa en documents separats: objectius, sabers, metodologia, atenció
a la diversitat, avaluació, rúbriques, seqüenciació anual i les 9 situacions
d'aprenentatge (SA1-SA9).

El document `08_Sequenciacio_temporal_anual.md` (pendent de crear) fixarà el quadre
d'hores del curs: SA1=6, SA2=8, SA3=8 (1r trimestre) · SA4=8, SA5=6, SA6=8
(2n trimestre) · SA7=8, SA8=6, SA9=10 (3r trimestre) → **68 h + marge**.
`tools/qa.py:comprova_hores()` validarà que la taula del document quadra amb aquest
subtotal.
