# Simulacions

Com treballar el codi del curs **sense maquinari** o abans de muntar el circuit
real amb micro:bit + Micro:shield + sensors Keyestudio.

> Comença per l'[**Índex de simulacions**](Index_simulacions.md) per saber quina
> eina fer servir i quan.

## Contingut

- [`Index_simulacions.md`](Index_simulacions.md) — punt d'entrada: quina eina
  fer servir per a cada cas.
- [`Simulador_microbit.md`](Simulador_microbit.md) — **l'eina principal del
  curs**: què simula exactament python.microbit.org i què no, ús per SA i límits.
- [`Wokwi_opcional.md`](Wokwi_opcional.md) — Wokwi, només per a l'ampliació
  opcional amb Raspberry Pi Pico (no forma part del maquinari nucli).
