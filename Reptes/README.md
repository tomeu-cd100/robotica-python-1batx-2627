# Reptes

Banc de **reptes triables per SA** (SA1 a SA8): l'ampliació ⭐ de cada situació
d'aprenentatge, per a qui ha acabat el nucli de la fitxa i vol anar més enllà.

> Cada SA té **3 reptes de dificultat creixent** (⭐/⭐⭐/⭐⭐⭐), tots amb el mateix
> requisit tècnic mínim però contextos ("client" i "lliurable") diferents: l'alumnat
> tria pel context que l'enganxi més, no per la dificultat.

## Contingut

- [`Reptes_SA1.md`](Reptes_SA1.md) a [`Reptes_SA8.md`](Reptes_SA8.md) — un
  document per SA, en ordre de dificultat (comença sempre per ⭐).
- [`Solucionari/`](Solucionari/README.md) — codi resolt de cada repte, **material
  del docent**: no es lliura a l'alumnat.

SA9 no té document de reptes propi: és el repte final integrador (projecte +
dossier + defensa oral), descrit a `Classes/SA9/`.
