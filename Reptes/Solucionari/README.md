# Reptes/Solucionari

Solucionari (codi resolt, MicroPython) dels tres reptes triables de cada SA1-SA8. És
material del **docent**: no es lliura a l'alumnat. Una subcarpeta `SAn/` per situació
d'aprenentatge, amb el codi complet de cada repte i un `.md` que en consolida
l'explicació (per exemple, [`SA1/Reptes_SA1_solucions.md`](SA1/Reptes_SA1_solucions.md)).

| SA | Solucionari |
|---|---|
| SA1 | [`SA1/`](SA1/Reptes_SA1_solucions.md) — targeta digital, semàfor d'humor, dau doble. |
| SA2 | [`SA2/`](SA2/Reptes_SA2_solucions.md) — llum de seguretat, ambientador, semàfor d'emergència. |
| SA3 | [`SA3/`](SA3/Reptes_SA3_solucions.md) — llum automàtica, aparcament, estació meteo. |
| SA4 | [`SA4/`](SA4/Reptes_SA4_solucions.md) — salutació d'aparador, aparcament de precisió, coreografia de benvinguda. |
| SA5 | [`SA5/`](SA5/Reptes_SA5_solucions.md) — xat de classe, comandament per gestos, històric de comandes. |
| SA6 | [`SA6/`](SA6/Reptes_SA6_solucions.md) — termòstat multizona, semàfor de vianants, vehicle amb alerta. |
| SA7 | [`SA7/`](SA7/Reptes_SA7_solucions.md) — seguidor avançat, evita-obstacles intel·ligent, rover autònom complet. |
| SA8 | [`SA8/`](SA8/Reptes_SA8_solucions.md) — estació d'alertes, estació multisensor, missió telemetrada. |
